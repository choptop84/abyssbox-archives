AbyssBox Archives

This website exists for users to use older versions of AbyssBox in the chance of a song becoming corrupted once AbyssBox 1.6/1.6.1 came out. If your song was corrupted due to these updates then I apologize for the inconvenience.

AbyssBox 0.8

The original release of AbyssBox. This version was released on January 1st of 2024.

AbyssBox 0.9

The first major update, includes fonts for themes, updates to existing themes, and three layouts.

AbyssBox 0.9.2

While typically we'll skip major versions for smaller patches to avoid having broken versions of AbyssBox (that by all means aren't that different from the major version), this one adds an older version of Supersaw justifying it being a different release.

AbyssBox 1.0

The first official release of AbyssBox. Includes a few new themes and an updated custom theme editor.

AbyssBox 1.1.1

The first major update after the official release. This update adds mobile UI changes, more changes to the custom theme editor, and updated/added many new themes.

AbyssBox 1.2

This update made major changes to the song player, allowing for song player layouts. This update also changed the url identifier from #u to #a, added a new layout, and added a few themes.

AbyssBox 1.3

This update added loop modes to the song, allowing you to quickly switch from looping a small section to looping the entire song, and even having it so the song doesn't loop at all.

AbyssBox 1.4.5

1.4 added the most themes any one update has ever seen, while also making a number of other visual changes.

AbyssBox 1.5.1

The first major update to add actual synth features, includes ring modulation and phaser. This update also included .ogg and .opus exporting.

AbyssBox 1.6

This update ported all of the features currently present in UltraBox 2.3, added Slarmoo's Box's envelopes, a font prompt, invert wave from Dogebox2, and many other features

AbyssBox 1.6.1

A patch of AbyssBox 1.6.1 that keeps all but one feature from AbyssBox 1.6, that being the enhanced envelopes.
